[![Continuous project validation](https://github.com/gama-platform/gama/actions/workflows/trigger-compilation.yaml/badge.svg)](https://github.com/gama-platform/gama/actions/workflows/trigger-compilation.yaml)

[![CodeScene Average Code Health](https://codescene.io/projects/51964/status-badges/average-code-health)](https://codescene.io/projects/51964)

GAMA is an open-source modeling and simulation environment for creating spatially explicit
agent-based simulations. This is its official source repository.

**[Download GAMA](https://github.com/gama-platform/gama/releases)** |
**[Website](https://gama-platform.org)** |
**[Documentation and tutorials](https://github.com/gama-platform/gama/wiki)**

## Community and contributions

For questions, use [GitHub Discussions](https://github.com/gama-platform/gama/discussions)
or the [mailing list](https://groups.google.com/g/gama-platform).
Report bugs and feature requests in the [issue tracker](https://github.com/gama-platform/gama/issues),
and documentation problems in the [website issue tracker](https://github.com/gama-platform/gama-platform.github.io/issues).

Contributions are welcome through pull requests. Read the
[contribution guidelines](.github/CONTRIBUTING.md) and
[development guide](https://github.com/gama-platform/gama/wiki/developingGAMA) before getting started.
