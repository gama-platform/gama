GAMA Developer Tools

This is an Eclipse update site. It is meant to be used from Eclipse, not browsed.

The GAMA Developer Tools add a GAMA menu to the Eclipse IDE used to develop GAMA. They provide:

  • wizards for new GAMA plugins, skills, operators, actions, types and test models;
  • a dialog-free Clean and Rebuild that resets the GAML annotation processor;
  • a configuration checker with quick fixes;
  • reports of undocumented and untested GAML elements.

Installation

You need an Eclipse IDE with JDT and PDE (e.g. Eclipse IDE for RCP and RAP Developers), running on Java 25.

  1. In Eclipse, choose Help > Install New Software...
  2. Click Add... and enter https://gama-platform.github.io/gama/devtools/ as the location.
  3. Select GAMA Developer Tools, then finish the wizard and restart Eclipse.

Eclipse then finds new versions through Help > Check for Updates.

The update site is rebuilt every time the developer tools change on the main branch. See the README of gama.ui.devtools for more information.
