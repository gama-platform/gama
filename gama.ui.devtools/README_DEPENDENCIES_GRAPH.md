# Static GAMA Dependencies Analysis

The class `DependencyGraphBuilder` is a static dependency graph generator relying on `jgrapht`. It also tries to figure out what are the services consuming/providing relations between libraries.<br/>
The class `GraphToHtml` is aimed at generating convenient html files for representing the graph generated by `DependencyGraphBuilder`.

`DependencyGraphBuilder` can save graphs in dot format, however, it only saves the dependencies graph, but not consuming/providing relations.

**Prior to any analyses, the module-info.class files located in `.jar` archives must be removed if they exist, or they will crash the native java dependency analyzing tool `jdeps`** 
To achieve this, you may use : 

```bash
find your/libs/path -type f -name '*.jar' -exec unzip -d {} module-info.class \;
```

## Exemple usage

```java
        final DependencyGraphBuilder builder = new DependencyGraphBuilder();
        final String librariesPathStr = "/path/to/target/libraries"; 

        Set<Path> libraries;
        
        builder.resolveLibrariesInDirectory(librariesPathStr);

        libraries = builder.getLibraries(); 

        builder.listServices();

        builder.generate();

        builder.checkServicesDependenciesRelations();

        GraphToHtml.generateHtml(builder,"./graph.html");

        builder.exportGraph("./graph.dot");
```
