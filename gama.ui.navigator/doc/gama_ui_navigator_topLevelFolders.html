Navigator top-level folders

Identifier:
gama.ui.navigator.topLevelFolders

Description:
Declares the GAMA navigator's built-in workspace categories and optional independent virtual hierarchies. Factories are instantiated lazily and their folders retained across workspace refreshes. Downstream folders do not register GAML extensions or classify local projects. Restart after installing or removing plug-ins.

Configuration Markup:

<!ELEMENT extension (folder+)>

<!ATTLIST extension

point CDATA #REQUIRED

id    CDATA #IMPLIED

name  CDATA #IMPLIED>


<!ELEMENT folder EMPTY>

<!ATTLIST folder

id       CDATA #REQUIRED

class    CDATA #REQUIRED

name     CDATA #IMPLIED

category (DATA|DEMOS|LIBRARY|RECIPES|TUTORIALS|TESTS|USER)

before   (data|demos|library|recipes|tutorials|tests|user)

order    CDATA #IMPLIED>

  • id - Globally unique, stable identifier, preferably qualified by the contributing plug-in ID. Built-in anchor IDs are reserved. Used for viewer identity and expansion-state persistence, not as the display label.
  • class - Public no-argument implementation of ITopLevelFolderProvider. Downstream providers must return a non-workspace TopLevelFolder attached to the supplied NavigatorRoot, promptly and without I/O. The navigator's own category declarations use WorkspaceFolderProvider.
  • name - Display name used by the built-in WorkspaceFolderProvider. Independent providers supply their folder's display name themselves; they may read this attribute through IExecutableExtension.
  • category - Navigator-owned workspace classification, not available to downstream plug-ins. When present, id must equal the lowercase category name and the declaration must belong to gama.ui.navigator. Omitting this attribute declares an independent non-workspace hierarchy.
  • before - Places this contribution immediately before a built-in folder in the logical ordering. Defaults to before User. The position is retained even when the anchor is hidden because it is empty. Contributions cannot anchor to one another.
  • order - Ascending integer priority among contributions at the same anchor, default 0. Equal priorities are ordered by contribution ID, not registry enumeration order. Workspace categories themselves use this value for their anchor ordering.
